## Open agenda
1. **Which chat surface to design first.** v0 has four: computer app, browser extension, mobile
   app ([D5](../DECISIONS.md)), and wearable voice.
   - `poc/live_video_chat`'s phone web UI is a reference for the *interaction* (camera, voice and
     stream feel), not code to reuse ([D7](../DECISIONS.md)). The mobile app is written fresh.
   - The mobile app also carries speech-output playback.
2. **The wearable interaction model.** Push-to-talk, capture indicators, and the consent
   affordances: pause, mute, delete-last-N.
   - Trust is a design problem as much as a platform one.
3. **What "the model knows my life" should feel like in an answer.** Tone, memory surfacing, and
   how it cites what it remembers without being creepy.
